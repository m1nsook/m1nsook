# hey, i'm miso 👋

I build **developer tools, desktop apps, and game-related software**. I like clean interfaces, local-first workflows, and projects that make complicated things feel simple.

Most of my work lives somewhere between **design and engineering** — I care about how software feels just as much as how it works.

## Currently building

### [Paglora](https://github.com/m1nsook/paglora)

An open-source, local-first documentation studio for writing, designing, and publishing documentation without needing a cloud account.

- Visual Markdown editing and reusable documentation components
- Desktop experience built with **Tauri, Rust, React, and TypeScript**
- Multilingual interfaces and portable static-site publishing

**Status:** Active, early development · [Source](https://github.com/m1nsook/paglora) · [Documentation](https://m1nsook.github.io/paglora-docs/)

### Around the project

- **[Paglora Docs](https://github.com/m1nsook/paglora-docs)** — the official documentation, created with Paglora itself.
- **[Paglora Languages](https://github.com/m1nsook/paglora-lang)** — community-driven translations for the Studio and generated websites.

## What matters to me

- **Local-first:** useful software shouldn't always need an account or an internet connection.
- **Good UX:** tools should be approachable without hiding their capabilities.
- **Open development:** clear documentation, thoughtful contributions, and software people can build on.
